See what is using your network: every connection, host, service, program and country, live from a network card, a capture file or your routers' NetFlow/IPFIX.

Start a capture

Needs administrator/root rights (the Net-monit service has them). No extra software is needed. On Windows, installing Npcap is optional: it adds MAC addresses, VLAN tags and advanced filters.

The file is analysed on the server as fast as it can be read.

Point the router/switch NetFlow v5, v9 or IPFIX export at this server and port. Allow the port in the firewall. UDP can be spoofed, so list the exporter addresses you trust; empty accepts every sender.

Examples: tcp port 443 · host 8.8.8.8 · udp and not port 53 · net 192.168.0.0/16

When to notify

Counts incoming plus outgoing in one second. Use k, M, G: 500k, 2.5M, 1G. The message lists the busiest hosts and services of that second.

Favorites are the hosts, services and programs you starred in Overview or Connections.

Add a blacklist file in Settings.

Where to send it

Every notification is also written to the log below and to the audit log.

Uses the SMTP settings and admin addresses already configured in Settings.
